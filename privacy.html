隱私權政策

最後更新：2026 年 11 月 24 日

「頻道自動發片工具」（以下稱本工具）是頻道主個人使用的程式，只在頻道主自己的電腦上執行，用來管理頻道主自己的 YouTube 頻道。

本工具會存取哪些資料

經頻道主在 Google 授權畫面同意後，本工具透過 YouTube 官方 API 使用以下權限：

  • 上傳影片到頻道主自己的頻道（youtube.upload）
  • 讀取頻道主自己頻道的基本資料與影片清單（youtube.readonly）
  • 讀取頻道主自己頻道的觀看數據（yt-analytics.readonly）

資料如何使用與保存

  • 資料只用來上傳影片、整理頻道成效報告、改進影片內容。
  • 授權憑證與數據只存在頻道主自己的電腦裡，不會上傳到任何伺服器。
  • 本工具不會出售、出租或分享任何資料給第三方，也不會用於廣告。
  • 本工具不會存取頻道主以外任何人的帳號或個人資料。

本工具使用 Google API 的方式

本工具使用與傳輸從 Google API 取得的資訊，遵守 Google API 服務使用者資料政策，包括「有限使用」的規定。本工具也使用 YouTube API 服務，使用者同意 YouTube 服務條款，相關資料處理也適用 Google 隱私權政策。

如何取消授權、刪除資料

  • 隨時可以到 Google 帳戶的「第三方連結」 移除本工具的存取權。
  • 刪除電腦裡的授權檔，本工具就無法再存取帳號。

聯絡方式

有任何問題，請透過問號研究所或迅雷新聞 YouTube 頻道頁面上的聯絡方式與頻道主聯絡。
